# Audit fixes, 24 October 2026

Owner approved all nine findings. Implemented locally; no deployment or game-data changes. Ponytail full: native browser dialogs, no added dependencies, one small point-validation test file.

## Changes by audit number

1. Native modal dialogs now contain focus, dismiss with Escape and restore focus. Nested cancel events stop propagation. A disabled opener falls back to an available control in its parent dialog. Multiplier supports click, Enter and Space; long press remains supported.
2. Calculator controls, simulator controls and modal controls have minimum 44px touch targets with gaps. Removed the small floating multiplier hit area.
3. Added visible focus indicators to points, claimed-through, support, select and buttons. Dark and light dialog focus colors have computed contrast above 3:1.
4. Added simulator error boundary with reload/return actions; loading allows cancellation. Calculator and fertilizer storage failures retain working state and show a retry action. Calculator saving runs from the same update that changes working state.
5. Shared normalization keeps claimed-through between zero and current points, including saved-state migration. Lowering points updates both displayed values. Invalid text gets feedback instead of being silently stripped into a different number. Tests cover shorthand, invalid text, negative input, nonfinite values and clamping.
6. Added the Event rewards h1. Simplified labels and raised supporting text to at least 13px. Retained Trebuchet MS and applied tabular numerals globally.
7. Replaced stacked resting-panel shadows and gradients with flat green surfaces. Preserved mark, reward images and game identity. Simulator sun/tree concepts use CSS shapes; decorative emoji removed.
8. Tablet next-milestone panel uses the full row. Desktop button sits below milestone progress, avoiding title/button collisions. Mobile controls form a three-column adjustment grid.
9. Empty rewards explain zero points, first milestone, all reached rewards claimed, or a fully claimed run. The empty message checks actual totals, so recurring Fishing Glitter Fruit no longer appears alongside a contradictory empty message. Existing recurring-fruit calculation was retained.
